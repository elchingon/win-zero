# Playground web export (archived)

A web-only game export (react-dom, lucide-react, "Playground SDK") that was dropped into the
Expo scaffold before Phase 1. It can't run in React Native, and its palette, weapons, and rules
differ from `docs/SPEC.md`. Kept here only for reference; it is excluded from tsc and jest.

The look-and-feel reference for the app is `docs/prototype/win-zero.html`.
